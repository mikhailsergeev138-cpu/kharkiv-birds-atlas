# Data folder

The download script writes `gbif_birds_sample.csv` here.

- The CSV is generated from the GBIF Occurrence API.
- It is not committed to the repository by default; run the script to create it locally.
- The current geographic filter is a rough bounding box and can include records outside Kharkiv Oblast.
- Keep source and filter details with any future analysis, and consult [GBIF citation guidance](https://www.gbif.org/citation-guidelines).
